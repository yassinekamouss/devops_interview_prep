# DevOps Engineering Knowledge Base

Welcome to your structured preparation portal for DevOps, Cloud, Containers, and Infrastructure concepts.

## Modules Covered

- **Kubernetes**: Architecture, controllers, networking (CNI, Ingress, Services), storage, and debugging workflows.
- **GitOps (ArgoCD)**: OpenGitOps principles, ArgoCD internal architecture, Application & ApplicationSet CRDs, Sync Waves, Progressive Delivery (Argo Rollouts), secrets management (ESO, Vault), and production troubleshooting.
- **Docker & Containers**: Multi-stage builds, rootless containers, networking drivers, volume mounts, and image layer caching optimization.
- **Git & Version Control**: Git internals, rebasing vs. merging, bisect, reflog, cherry-pick, conflict resolution, and branching workflows (Trunk-based, Gitflow).
- **CI/CD**: Pipelines, GitHub Actions, Jenkins, DevSecOps, deployment strategies, and DORA metrics.
- **Infrastructure as Code**: Terraform state management, remote backends, modules, and drift detection.
- **Linux & Networking**: Kernel internals, TCP/IP stack, troubleshooting tools (`tcpdump`, `strace`, `ss`, `cgroups`, `namespaces`).
