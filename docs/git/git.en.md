# Git - Modular Revision Path

The Git course is divided into short, progressive modules to reinforce hands-on practice before a DevOps interview.

## Recommended Path
1. Fundamentals
2. Core Concepts
3. Practice
4. Advanced Concepts
5. Troubleshooting
6. Best Practices
7. Interview Questions

## Git Modules
1. [01 - Fundamentals and Lifecycle](01-fondamentaux-cycle.md)
2. [02 - Commits and History](02-commits-historique.md)
3. [03 - Branches and Merge](03-branches-merge.md)
4. [04 - Conflicts and Rebase](04-conflits-rebase.md)
5. [05 - Reset, Revert and Amend](05-reset-revert-amend.md)
6. [06 - Stash](06-stash.md)
7. [07 - Workflow and Best Practices](07-workflow-bonnes-pratiques.md)
8. [08 - Cheatsheet and Interview Questions](08-cheatsheet-entretien.md)

## Interview Revision Tips
- Replay commands locally on a test repository.
- Explain merge/rebase and reset/revert differences out loud.
- Finish with module 08 in timed Q&A mode.
