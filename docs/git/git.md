# Git - Parcours de revision modulaire

Le cours Git est decoupe en modules courts et progressifs pour renforcer la pratique avant entretien DevOps.

## Parcours recommande
1. Fondamentaux
2. Concepts principaux
3. Pratique
4. Concepts avances
5. Troubleshooting
6. Best practices
7. Interview questions

1. [01 - Fondamentaux et cycle de vie](01-fondamentaux-cycle.md)

4. [04 - Conflits et rebase](04-conflits-rebase.md)
5. [05 - Reset, revert et amend](05-reset-revert-amend.md)
6. [06 - Stash](06-stash.md)
7. [07 - Workflow et bonnes pratiques](07-workflow-bonnes-pratiques.md)
8. [08 - Cheatsheet et questions d'entretien](08-cheatsheet-entretien.md)

## Conseils de revision entretien
- Rejouer les commandes en local sur un depot de test.
- Expliquer les differences merge/rebase et reset/revert a voix haute.
- Finir par le module 08 en mode questions-reponses chrono.
