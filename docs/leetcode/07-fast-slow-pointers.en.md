# Fast and Slow Pointers

## Trigger phrases

- Cycle
- Loop
- Middle of a linked list
- Detect a repeated state

## Idea / Intuition

Use two pointers:

- `slow` → advance 1 step
- `fast` → advance 2 steps

If the two pointers meet → a cycle exists.

## Recognition rule

!!! tip "Ruler"
Cycle / Milieu → **Fast + Slow Pointers**
