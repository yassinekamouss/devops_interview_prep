# Intervals

## Trigger phrases

- Intervals
- Ranges
- Overlap
- Meetings
- Schedule
- Start/end

## Example

```text
[1,3]
[2,6]
```

These intervals overlap, so: `[1,6]`

## Standard approach

```text
Trier par début → Traiter les intervalles → Fusionner / compter / supprimer
```

## Recognition rule

!!! tip "Ruler"
Ranges + Overlap → **Sort + Intervals**
