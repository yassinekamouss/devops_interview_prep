# Minimum Spanning Tree (MST)

MST is a different problem than the shortest path.

| Shortest path | MST |
|---|---|
| What is the cheapest path from A to B? | What is the cheapest way to connect ALL nodes? |

## Algorithms

- Kruskal
- Prim

## Recognition rule

!!! tip "Ruler"
Connect EVERYTHING with minimal total cost → **MST**

## Typical problems

- Min Cost to Connect All Points
- Connecting Cities With Minimum Cost
