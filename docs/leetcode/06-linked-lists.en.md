# Linked Lists

## Important operations

Most linked list problems revolve around three pointers:

- `prev`
- `current`
- `next`

For an inversion:

```text
current.next = prev
```

Then we advance the pointers.

## Trigger phrases

- Node
- Next
- Linked list
- Reverse
- Remove node
- Merge lists
- Cycle
