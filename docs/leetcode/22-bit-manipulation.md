# Bit Manipulation

## Phrases déclencheuses

- XOR
- Binaire
- Bits
- Puissance de 2
- Chaque élément apparaît deux fois sauf un
- Nombre manquant

## Exemple

```text
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
```

Comme `x ^ x = 0`, les paires s'annulent (`1^1=0`, `2^2=0`), il ne reste que `4`.

## Problèmes typiques

- Single Number
- Number of 1 Bits
- Counting Bits
- Missing Number
- Power of Two
