# Greedy

## Central idea

Make the best local choice and never need to reconsider.

The critical interview question is:

> Can I prove that this local choice is still safe?

## Trigger phrases

- Maximum number
- Minimum number
- Termination as soon as possible
- Scheduling
- Achievability
- Locally optimal choice

## Recognition rule

!!! tip "Ruler"
Can a locally optimal choice be proven globally optimal? → **Greedy**

## Typical problems

- Jump Game
- Jump Game II
- Gas Station
- Partition Labels
- Non-overlapping Intervals
- Activity Selection
