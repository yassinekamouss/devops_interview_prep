# Pattern Combinations

Les problèmes d'entretien les plus difficiles combinent souvent plusieurs patterns. Voici les combinaisons à reconnaître :

| Combinaison | Usage typique |
|---|---|
| Hash Map + Sliding Window | Plus longue sous-chaîne |
| Hash Map + Prefix Sum | Subarray Sum K |
| Heap + Hash Map | Top K Frequent |
| Binary Search + Greedy | Koko Eating Bananas |
| DFS + Mémoïsation | Optimisation de grille/chemin |
| BFS + Hash Set | Word Ladder |
| DFS + Backtracking | Word Search |
| Sorting + Two Pointers | 3Sum |
| Sorting + Greedy | Intervals |
| Graph + BFS | Plus court chemin non pondéré |
| Graph + Dijkstra + Heap | Plus court chemin pondéré |
| Graph + Union Find | Connectivité |
| Tree + DFS | Problèmes de profondeur/chemin/sous-arbre |
| Tree + BFS | Problèmes par niveau |
| Monotonic Stack + Array | Prochain plus grand / histogramme |

!!! tip "Comment utiliser cette page"
    Quand un problème vous semble « ne pas rentrer dans une seule case », vérifiez d'abord s'il correspond à l'une de ces combinaisons avant de chercher un pattern totalement nouveau.
