# Topological Sort

## Phrases déclencheuses

- Prerequisites (prérequis)
- Dependencies (dépendances)
- Ordering (ordonnancement)
- Must happen before
- Course dependencies
- Build dependencies

## Idée / Intuition

```text
A → B
```

signifie : `A` doit se produire avant `B`. Cela forme naturellement un graphe dirigé.

## Règle de reconnaissance
