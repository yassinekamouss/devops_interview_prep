# Trie

## Phrases déclencheuses

- Préfixe
- Dictionnaire
- Autocomplétion
- Commence par (starts with)
- Recherche de mots
- Correspondance de préfixe

## Exemple

```text
car
card
care
cat
```

Si vous vous demandez fréquemment : « Existe-t-il un mot commençant par `ca` ? » → pensez **Trie**.
