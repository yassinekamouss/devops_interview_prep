# Bit Manipulation

## Trigger phrases

-XOR
- Binary
- Bits
- Power of 2
- Each item appears twice except one
- Missing number

## Example

```text
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
```

Like `x ^ x = 0`, the pairs cancel each other (`1^1=0`, `2^2=0`), only `4` remains.

## Typical problems

- Single Number
- Number of 1 Bits
- Counting Bits
- Missing Number
- Power of Two
