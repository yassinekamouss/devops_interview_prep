# Greedy

## Idée centrale

Faire le meilleur choix local et ne jamais avoir besoin de le reconsidérer.

La question critique en entretien est :

> Puis-je prouver que ce choix local est toujours sûr ?

## Phrases déclencheuses

- Nombre maximum
- Nombre minimum
- Terminaison la plus tôt possible
- Ordonnancement
- Atteignabilité
- Choix localement optimal

## Règle de reconnaissance

!!! tip "Règle"
    Un choix localement optimal peut-il être prouvé globalement optimal ? → **Greedy**

## Problèmes typiques

- Jump Game
- Jump Game II
- Gas Station
- Partition Labels
- Non-overlapping Intervals
- Activity Selection
