# Topological Sort

## Trigger phrases

- Prerequisites (prerequisites)
- Dependencies
- Ordering
- Must happen before
- Course dependencies
- Build dependencies

## Idea / Intuition

```text
A → B
```

means: `A` must occur before `B`. This naturally forms a directed graph.
