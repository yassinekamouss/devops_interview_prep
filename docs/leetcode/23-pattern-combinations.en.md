# Pattern Combinations

The most difficult maintenance problems often combine several patterns. Here are the combinations to recognize:

| Combination | Typical usage |
|---|---|
| Hash Map + Sliding Window | Longest substring |
| Hash Map + Prefix Sum | Subarray Sum K |
| Heap + Hash Map | Top K Frequent |
| Binary Search + Greedy | Coco Eating Bananas |
| DFS + Mémoïsation | Grid/Path Optimization |
| BFS + Hash Set | Word Ladder |
| DFS + Backtracking | Word Search |
| Sorting + Two Pointers | Infallible |
| Sorting + Greedy | Intervals |
| Graph + BFS | Unweighted shortest path |
| Graph + Dijkstra + Heap | Weighted shortest path |
| Graph + Union Find | Connectivity |
| Tree + DFS | Depth/path/subtree issues |
| Tree + BFS | Problems by level |
| Monotonic Stack + Array | Next largest / histogram |

!!! tip "How to use this page"
When a problem seems like it "doesn't fit into one box", first check to see if it fits one of these combinations before looking for a completely new pattern.
