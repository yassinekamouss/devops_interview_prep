# Minimum Spanning Tree (MST)

Le MST est un problème différent du plus court chemin.

| Plus court chemin | MST |
|---|---|
| Quel est le chemin le moins cher de A à B ? | Quel est le moyen le moins cher de connecter TOUS les nœuds ? |

## Algorithmes

- Kruskal
- Prim

## Règle de reconnaissance

!!! tip "Règle"
    Connecter TOUT avec un coût total minimal → **MST**

## Problèmes typiques

- Min Cost to Connect All Points
- Connecting Cities With Minimum Cost
